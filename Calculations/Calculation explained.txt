Python to LaTeX calculation export

This setup is used to keep engineering calculations in Python, while still being
able to use the calculated values directly inside the LaTeX report.

The calculations are written in separate Python files. For example,
motor_calculation.py contains the input values and calculations for the motor.
Other calculation files can be added later, such as shaft_calculation.py,
beam_calculation.py or force_calculation.py.

Folder structure

- Calculations/.py
  Contains the actual calculation files, such as motor_calculation.py.

- Calculations/main.py
  Main Python file. Run this file to collect all calculation results and export
  them to LaTeX. New calculation files are connected here.

- Calculations/ExportToLaTex
  Contains latex_export.py. This file contains the general LaTeX export tools,
  such as LatexResult and the function that writes calculated_values.tex.

- LaTex/calculated_values.tex
  This file is generated automatically. Do not edit it by hand.

- Calculations/requirements.txt
  Contains the Python libraries used for calculations, plots, control systems,
  units, data analysis and hardware communication.


Python libraries

The base setup contains these libraries:

- numpy
  Matrix and vector calculations.

- scipy
  Optimisation, ODEs and signal processing.

- matplotlib
  Engineering graphs and visualisation.

- pandas
  Measurement data, CSV files and Excel analysis.

- sympy
  Symbolic calculations.

- control
  Transfer functions, state-space models, PID analysis and Bode plots.

- pint
  Calculations with physical units.

- pyserial
  Communication with Arduino, STM32 and other hardware.

Install them with:

pip install -r Calculations/requirements.txt


Important idea

Keep the calculation itself separate from the LaTeX export.

For simple calculations it is possible to directly return LatexResult objects,
but that becomes unclear when the calculation grows. Therefore, each calculation
file should preferably use this structure:

1. Define the input values.
2. Define a results dataclass for the normal calculation output.
3. Write a calculation function that only calculates values.
4. Write a separate export function that converts selected results to
   LatexResult objects.

This keeps the engineering calculation readable, while still making it easy to
export selected values to LaTeX.


LatexResult

Each value that must be exported to LaTeX is stored as a LatexResult object.
A LatexResult contains three things:

1. The LaTeX command name.
2. The calculated numerical value.
3. The number format that should be used in the generated LaTeX file.

Example:

LatexResult(
    command_name="MotorTorque",
    value=results.motor_torque,
    number_format=".3f",
)

This will be written to the generated LaTeX file as:

\newcommand{\MotorTorque}{0.125}


Generated LaTeX file

The generated file is called calculated_values.tex. This file is created
automatically when main.py is run. If the file already exists, it is
overwritten.

The generated file should not be edited by hand. If a value is wrong or if a new
value is needed, the Python calculation file should be changed and main.py
should be run again.

The main LaTeX document loads the generated file with:

\input{calculated_values.tex}

After that, the command can be used anywhere in the LaTeX document. For example:

The motor torque is \(\MotorTorque~\si{\newton\metre}\).

Using \MotorTorque directly inside \qty or \SI can sometimes give problems,
because siunitx expects a literal number. The safer form is:

\MotorTorque~\si{\newton\metre}


Basic workflow

1. Add or change calculations in a separate Python calculation file.
2. Return the normal calculation output with a dataclass.
3. Convert only the values needed in the report to LatexResult objects.
4. Add the calculation result function to collect_results() in main.py.
5. Run main.py.
6. Use the generated LaTeX commands in the report.


---------
Example calculation file

from __future__ import annotations

from dataclasses import dataclass

from latex_export import LatexResult


MOTOR_CURRENT_A = 2.5
TORQUE_CONSTANT_NM_PER_A = 0.05
PULLEY_RADIUS_M = 0.012


@dataclass(frozen=True)
class MotorResults:
    motor_torque: float
    belt_force: float


def calculate_motor() -> MotorResults:
    motor_torque = MOTOR_CURRENT_A * TORQUE_CONSTANT_NM_PER_A
    belt_force = motor_torque / PULLEY_RADIUS_M

    return MotorResults(
        motor_torque=motor_torque,
        belt_force=belt_force,
    )


def calculate_motor_results() -> dict[str, LatexResult]:
    results = calculate_motor()

    return {
        "motor_torque": LatexResult(
            command_name="MotorTorque",
            value=results.motor_torque,
            number_format=".3f",
        ),
        "belt_force": LatexResult(
            command_name="BeltForce",
            value=results.belt_force,
            number_format=".2f",
        ),
    }


Adding a new calculation file

If a new calculation file is created, for example shaft_calculation.py, it should
also contain a normal calculation function and a separate LaTeX export function.

Example:

from __future__ import annotations

from dataclasses import dataclass

from latex_export import LatexResult


SHAFT_SPEED_RAD_PER_S = 12.0
SHAFT_TORQUE_NM = 0.125


@dataclass(frozen=True)
class ShaftResults:
    shaft_power: float


def calculate_shaft() -> ShaftResults:
    shaft_power = SHAFT_SPEED_RAD_PER_S * SHAFT_TORQUE_NM

    return ShaftResults(
        shaft_power=shaft_power,
    )


def calculate_shaft_results() -> dict[str, LatexResult]:
    results = calculate_shaft()

    return {
        "shaft_power": LatexResult(
            command_name="ShaftPower",
            value=results.shaft_power,
            number_format=".2f",
        ),
    }


The new calculation file must then be connected in main.py:

def collect_results() -> dict[str, LatexResult]:
    from motor_calculation import calculate_motor_results
    from shaft_calculation import calculate_shaft_results

    results = {}

    results.update(calculate_motor_results())
    results.update(calculate_shaft_results())

    return results

After running main.py, the generated LaTeX file will contain commands
such as:

\newcommand{\MotorTorque}{0.125}
\newcommand{\BeltForce}{10.42}
\newcommand{\ShaftPower}{1.50}

These values can then be used in the LaTeX report:

The motor torque is \(\MotorTorque~\si{\newton\metre}\).
The belt force is \(\BeltForce~\si{\newton}\).
The shaft power is \(\ShaftPower~\si{\watt}\).


Important notes

The LaTeX command name must only contain letters. Do not include the backslash
in the Python command_name field. For example, use "MotorTorque" instead of
"\MotorTorque".

The export script checks for invalid command names. It also checks for NaN and
infinite values, because these should not be written into a LaTeX report.

All paths in main.py and latex_export.py are built relative to the location of
the Python files. This makes the setup more reliable when it is run from a
different working directory.
